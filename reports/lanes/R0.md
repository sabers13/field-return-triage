The tests prove, among other things: the frozen enum vocabularies and versions, that
contracts are frozen and closed, that a safety flag requires its quote (and a quote
requires the flag), that quote-check counts add up, that decision changes require a
reason, that weeks start on Monday, that run manifests validate their hash and ordering,
that `TriageCard` has no close/scrap/return field, that every CLI stub names its lane and
exits non-zero, that the scanners catch their patterns without printing the value, that
the network block is actually armed, and that the facts checker passes the scaffold and
enforces rows once `project-facts.yml` exists.

## Deviations and judgement calls

- **Facts checker in scaffold mode.** `make facts` must be green now, but `README.md`,
  `METHOD.md` and `project-facts.yml` are R9's deliverables. The checker therefore
  prints `not built yet (lane R9)` and passes while `project-facts.yml` is absent; the
  moment that file exists the full literal check runs, including required release files,
  the README proof table and the YAML numbers. This is a stub in the sense the brief
  allows, not a relaxation of the final gate.
- **M0 not merged.** `which-ai-model`'s `config/forbidden.sha256` on `main` still has
  four hashes; the file here is that file plus the three v1.1 lines from the brief, as
  instructed.
- **Reference code.** The scanner, guard and facts patterns were read from the
  `which-ai-model` lane worktree where the scaffold had been built, because the primary
  checkout held planning files only at the time. Nothing was written outside this
  worktree.
- **Support contracts.** `FaultCode`, `Mileage`, `Reason`, `DroppedClue`, `SeriesKey`,
  `WeeklyCount`, `Recall` and `ModelSetting` were added as named types because the brief's
  core types need them and unnamed `dict` fields would lose the freeze. Documented in
  `docs/INTERFACES.md`.
- **`.opencode/`** is local harness state injected into the worktree; it is gitignored
  and never committed.
