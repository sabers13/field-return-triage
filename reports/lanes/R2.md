# R2 — Extraction and model client

Status: done on `fm/frt-r2`. `make test` green (116 tests), strict mypy clean,
`make lint` and both scanners clean.

## What was built

### `src/field_return_triage/llm/`

- **`client.py`** — `ChatClient`, one model per client. Record mode posts to
  `ModelSetting.base_url + /chat/completions` with the documented User-Agent
  (`field-return-triage/1.0 (+https://github.com/sabers13/field-return-triage)`) and a
  stable `x-opencode-session` per instance. It tries JSON-schema `response_format`
  first; a 400 that names the parameter switches that client to JSON mode permanently
  and re-sends the same request once. Retries cover transport errors and 429 only,
  honouring `Retry-After` (seconds or HTTP date) and backing off exponentially with
  `config/budget.toml` limits. A bad answer is returned, never retried. A 403, or an
  abuse/policy/suspension body, latches a process-wide stop and writes
  `reports/STOP.md`. `Message` is the role/content protocol from the interface.
- **`credentials.py`** — `load_api_key` reads the process environment, then the
  `FRT_ENV_FILE` file, then `.env`. Names tried, in order: `FRT_API_KEY`,
  `OPENCODE_GO_API_KEY`, `OPENCODE_API_KEY`. `ApiKey.reveal()` is called only to build
  the `Authorization` header; `repr` and `str` are redacted, and error/stop text is
  scrubbed before it can be stored or raised.
- **`record.py`** — `recording_key` =
  `sha256(model id \n prompt version \n sha256(canonical JSON of messages))` and
  `Recorder`. One JSONL file per model under `recordings/`; a row holds `key`,
  `model_id`, `prompt_version`, `content`, `usage.{input_tokens,output_tokens}` and
  `cost_usd` - no request, headers or credential. Replay reads the file only and
  raises `ReplayMissError` on a miss.
- **`cost.py`** — gateway USD list cost when a response carries one (`cost_usd`,
  `list_cost`, `total_cost`, `cost`, `usage.*`, or `x-opencode-cost-usd`), else tokens
  x `config/prices.toml`. `estimate_cost_usd` is the conservative pre-run bound: 1,000
  input tokens per item, the full output allowance, and the higher of peak/off-peak
  prices; it refuses a model the table cannot price.
- **`pacing.py`** — one `Pacer` per client: a bounded semaphore for concurrency and a
  rolling-minute window for request starts, both injected-clock testable.
- **`policy.py`** — the process-wide latch behind `PolicyStopError`, its pattern list,
  and the one-time `reports/STOP.md` writer.
- **`settings.py`**, **`reply.py`**, **`errors.py`**, **`__init__.py`**.

### `src/field_return_triage/extract/`

- **`prompt.py`** — prompt `e1`: sorted groups with one-line descriptions plus
  `unclear`, both kind vocabularies, "quote the exact words, never paraphrase", safety
  quote/null rule, and one JSON object with every key.
- **`schema.py`** — the JSON-schema wire model (`ExtractionAnswer`) handed to
  `response_format`; it is re-validated through the frozen `Extraction` contract.
- **`parse.py`** — fences stripped; empty, cut-off, unparseable, non-object and
  schema-breaching answers return `(None, "schema-invalid: <why>")`. Pure, so nothing
  is retried.
- **`quotecheck.py`** — whitespace-collapsed, case-folded verbatim matching for safety,
  symptom, condition, fault-code and mileage quotes; failures are kept in `dropped`
  with `checked == passed + len(dropped)`.
- **`run.py`** — `extract()`: prompt, one call, parse, quote check.

### Configuration and notes

- `config/prices.toml`: the gateway's USD-per-1M-token table from the OpenCode Go docs
  (read 2026-10-31), including DeepSeek peak/off-peak. Gemini 4 Argon has no input
  price on that page, so it is deliberately absent; the estimate refuses to invent one.
- `config/budget.toml`: USD 3 cap, 2 concurrent, 30/minute, 4 attempts, 0.5 s backoff,
  60 s timeout.
- `docs/GATEWAY_NOTES.md`: what the docs state and do not state (structured output,
  per-response USD cost, 429 handling, key variable name).

## Tests

116 tests. `tests/llm/` covers the fake transport cases the brief names: success (URL,
headers, body, usage and token cost), 429 then success honouring `Retry-After`, 403
stop with `STOP.md` and a second client blocked without touching the transport, an
abuse-text 400 stop, a bad answer that is called exactly once, JSON-schema rejection
falling back to JSON mode, transport errors retried and exhausted, replay miss with a
transport that would fail the test, record-then-replay equality, credential order and
redaction, no key in `repr`, logs or error text, recording row keys, price/estimate
math, budget validation and pacer behaviour. `tests/extract/` covers prompt content,
parse outcomes, every quote-check field, failing quotes, and record-then-replay giving
identical extraction output.

Run: `make test`, `make lint`, `make typecheck`, `make scan-forbidden`,
`make scan-secrets` - all green. No network in tests (the suite's socket guard is
armed), no paid call made, no key read from any real file.

## Deviations from the lane text

1. **`pyproject.toml` and `uv.lock`** gained `httpx==0.28.1` (plus its locked
   transitive dependencies). The lane needs an HTTP client and the scaffold did not
   carry one; this is the smallest additive shared change.
2. **`docs/GATEWAY_NOTES.md`** is written by R2 because the brief requires it, although
   `docs/` otherwise belongs to R9. It contains gateway facts only.
3. **`ModelReply` lives in `llm/reply.py`** and is re-exported from
   `llm/client.py`, so the interface path `llm.client.ModelReply` is unchanged while
   `record.py` avoids a circular import.
4. **Structured output is negotiated, not assumed.** The Go docs are silent on
   `response_format`, so the client attempts JSON schema, then falls back on a 400 that
   names the parameter. This costs one extra request only on an endpoint that rejects
   it; it never retries a model answer.
5. **Recording storage is one JSONL per model**, not one file per key. Rows still hold
   content, usage, cost and the key fields only. The filename is the model id with
   non-filesystem characters replaced.
6. **Invalid-answer reasons are prefixed `schema-invalid:`** (for example
   `schema-invalid: cut-off answer: ...`) so R6 can count them with one rule while the
   text still names the cause.
7. **A set-but-missing `FRT_ENV_FILE` raises `ConfigurationError`** instead of silently
   falling through to `.env`: a configured path that does not exist is an operator
   error, and replay mode never resolves a credential at all.
8. **`config/models.lock.toml` does not exist yet** (R7 owns it). `load_model_settings`
   raises a clear `ConfigurationError`; tests write a temporary lock file.
