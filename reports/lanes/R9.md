## Deviations

None from the method. Two documentation choices are worth recording:

1. **`make index` is in the quickstart before `make all`.** `make setup` runs `uv sync`
   without the optional `index` extra (deliberately kept out of the default environment),
   and `frt triage` must embed the query even when the cached index exists. Without the
   extra, a fresh clone fails at `index-cached`/`triage`. `make index` installs the extra
   and builds the library index once.
2. **The example is a committed evaluation narrative.** `frt triage` is replay-only, so
   arbitrary text has no recorded answer. The quickstart uses a recorded item and the
   limits section says so plainly.

No code, results, page or review files were changed.
